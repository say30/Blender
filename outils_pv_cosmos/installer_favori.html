Favori « PV COSMOS »

Il lit les informations du ticket COSMOS ouvert et les prépare pour le PV Excel. Il ne modifie rien dans COSMOS.

1. Installer le favori (une seule fois)

  1. Affiche la barre des favoris : Ctrl + Maj + B.
  2. Fais glisser ce bouton dans la barre des favoris :

    PV COSMOS

Si le glisser-déposer ne marche pas
  1. Clic droit sur la barre des favoris, puis Ajouter une page (ou « Ajouter un favori »).
  2. Nom : PV COSMOS.
  3. URL : colle tout le texte ci-dessous (bouton « Copier »).

Favori MON SECTEUR

Tâches actives de mes groupes, par ville, avec filtres (villes, libres / à moi, type, retard). Fais glisser :

MON SECTEUR

2. Utilisation

  1. Ouvre le ticket SCTASK dans COSMOS.
  2. Clique sur le favori PV COSMOS. Un panneau s'ouvre à droite avec les informations trouvées.
  3. Vérifie le type de PV et les champs. Les cases jaunes sont vides : tu peux les compléter. Les boutons « → installé » et « → restitué » du tableau des actifs remplissent les champs à partir du matériel affecté à la personne.
  4. Clique sur Copier pour le PV.
  5. Dans le PV Excel : Ctrl + Maj + I.
